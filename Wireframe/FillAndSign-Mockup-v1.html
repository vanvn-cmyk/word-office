Session 12 · Fill & Sign category

Fill & Sign — Mockup v1

3 new tools grouped under a single Tools tab category: Fill Form (free-text overlay on any PDF), Sign (draw signature with PencilKit → stamp onto PDF), Print (AirPrint system sheet). All 3 native, on-device, no third-party SDK.

Category layout: new "Fill & Sign" section in ToolsTabView, placed after "Organize" (Merge/Split). Same list-row style as organizeList. 3 rows: Fill Form → Sign → Print (ordered by user-value frequency, not implementation order).

Tech stack: Fill Form & Sign both use PDFView (PDFKit) + PDFAnnotation. Sign adds PKCanvasView (PencilKit). Print reuses UIPrintInteractionController via existing AirPrintCoordinator (Session 6). All native — no ZIPFoundation/GRDB/Artifex needed.

Post-processing: Sign/Fill Form output = new PDF file written to Documents/ → auto-navigate to editor (single-file, matching Session 11 gallery decision). Print doesn't produce a file — toast "Sent to printer" + stay at picker.

Decisions baked in (override any):

1. Ship order: Print first (backend done — session hôm nay), then Sign (session sau), then Fill Form (session sau nữa). Category section shows all 3 rows from day one — Sign/Fill rows are wired but their views show a "Coming soon" placeholder until built.

2. Post-processing: Sign/Fill produce PDF files → same auto-navigate-to-editor pattern as Session 11 (single-file → editor, matches Merge/Convert). Print → toast only, stay at picker (no output file to open).

3. Sign tier: Tier 1 (drawing image) only. Tier 2 PKI cert-based → Phase 2 per spec §9.1.

4. Fill Form scope: Option B (free-text overlay tap-anywhere). Option A (AcroForm auto-detect widget fields) skip for MVP — not in spec Phase0-v2, add later if user asks.

5. Print scope: PDF only. Office (DOCX/XLSX/PPTX) must Convert → PDF first via existing Convert tool. Rationale: UIPrintInteractionController accepts image/PDF directly but Office format render needs pipeline we already have.

6. Session commit: today's work (Print + category shell + 2 placeholder rows) becomes 1 commit; each of Sign, Fill Form becomes its own commit later.
